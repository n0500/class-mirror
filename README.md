# مرآة الصف

منصة سريعة لتقييم أداء الفصول، أُعدّت لـ المتوسطة الرابعة والثانوية الثانية بالرس.
تمسح المعلمة رمز QR الملصق في الفصل، فتختار المادة ثم التقدير، ويُحفظ التقييم مباشرة مع التاريخ والوقت، دون تسجيل دخول.

## الصفحات

| الصفحة | الوصف | من يستخدمها |
|---|---|---|
| `index.html?c=m2-1` | صفحة تقييم الفصل (يُحدَّد الفصل من الرابط) | المعلمات عبر QR |
| `dashboard.html` | لوحة المتابعة: المؤشرات، والتوزيع حسب الفصل والمادة، والسجل، والتصدير | الإدارة فقط (بتسجيل دخول) |
| `cards.html` | بطاقات الفصول العشرين للطباعة، كل بطاقة في صفحة A4 مع QR خاص | الإدارة |

## الملفات

```
index.html          صفحة المعلمة
dashboard.html      لوحة المتابعة
cards.html          بطاقات QR
config.js           الإعدادات (الملف الوحيد الذي يلزم تعديله)
firestore.rules     قواعد حماية قاعدة البيانات (تُلصق في Firebase)
assets/common.js    الفصول والمواد وطبقة الحفظ
assets/style.css    الهوية البصرية
assets/qrcode.js    مولّد رموز QR (يعمل داخل الموقع دون خدمة خارجية)
```

## وضع التجربة

ما دام ملف `config.js` لم يُعدَّل، يعمل الموقع في «وضع التجربة»: تُحفظ التقييمات في الجهاز نفسه فقط، وتظهر في لوحة المتابعة دون تسجيل دخول، مع زر لإضافة بيانات تجريبية. يفيد ذلك في معاينة الموقع قبل ربط قاعدة البيانات.

## خطوات النشر (من الجوال)

### ١) رفع الموقع على GitHub Pages (بالملف المضغوط)
1. أنشئي مستودعًا جديدًا باسم `miraat` (عامًّا Public) مع تفعيل خيار «Add a README file».
2. **مرة واحدة فقط:** من **Add file ← Create new file** اكتبي اسم الملف:
   `.github/workflows/deploy.yml`
   والصقي محتوى ملف `deploy.yml`، ثم **Commit changes**.
3. من **Settings ← Pages** اختاري: Source = **GitHub Actions**.
4. من **Add file ← Upload files** ارفعي الملف المضغوط `.zip` كما هو، ثم **Commit changes**.
5. يتولى الإجراء الآلي تلقائيًا: فك الملف، ووضع كل ملف في مكانه، وحذف الملف المضغوط، ثم نشر الموقع. تابعي التقدم من تبويب **Actions** (العلامة الخضراء تعني النجاح).
6. يصبح الموقع متاحًا على: `https://اسم-المستخدم.github.io/miraat/`

**عند كل تحديث لاحق:** ارفعي الملف المضغوط الجديد فقط، دون حذف الملفات القديمة.
- إن كانت نسخة `config.js` أو `firestore.rules` داخل الحزمة تحتوي القيم المؤقتة («ضعي_…») فلن تحل محل ملفاتك التي أدخلتِ فيها إعداداتك الحقيقية.
- الحزمة يمكن أن تحتوي مجلدًا رئيسيًا أو ملفات متفرقة؛ فالملفات ذات الامتداد `.js` و`.css` والصور تُنقل إلى `assets/`، وصفحات `.html` تبقى في الجذر.
- أي ملف `.js` أو `.css` يُرفع منفردًا إلى الجذر بالخطأ يُنقل تلقائيًا إلى `assets/`، ما عدا `config.js`.

### ٢) إنشاء قاعدة البيانات في Firebase
1. من [console.firebase.google.com](https://console.firebase.google.com) أنشئي مشروعًا جديدًا (مثل `miraat-alsaf`).
2. **Build ← Firestore Database ← Create database**: اختاري `Production mode`، والموقع `me-central2 (Dammam)`.
3. افتحي تبويب **Rules**، والصقي محتوى ملف `firestore.rules`، ثم **Publish**. البريد المكتوب فيه هو بريد **المالكة**.
4. **Build ← Authentication ← Get started**، ثم فعّلي `Email/Password`.
5. أنشئي حساب المالكة من `dashboard.html` ← «إنشاء حساب» بالبريد المكتوب في القواعد.
6. من **Authentication ← Settings ← Authorized domains** أضيفي: `اسم-المستخدم.github.io`

### ٣) ربط الموقع بقاعدة البيانات
1. **Project settings (رمز الترس) ← Your apps ← Web (`</>`)**، سجّلي التطبيق، وانسخي قيم `firebaseConfig`.
2. عدّلي `config.js` في GitHub: الصقي القيم مكان القيم الحالية.
3. بعد دقيقة افتحي `dashboard.html` وسجّلي الدخول.

### ٤) طباعة البطاقات
افتحي `cards.html` **من الرابط النهائي للموقع** (لأن رمز QR يتضمن عنوان الموقع الذي فُتحت منه الصفحة)، ثم «طباعة / حفظ PDF». يمكن أيضًا اختيار فصل واحد لطباعة بطاقته فقط.

> عند الطباعة: المقاس A4، والهوامش «بلا» (None)، مع تفعيل «رسومات الخلفية».

## حسابات الإدارة
- **المالكة** (البريد المكتوب في `firestore.rules`): تنشئ حسابها أول مرة من تبويب «إنشاء حساب» في `dashboard.html`.
- **رابط الدعوة**: يظهر للمالكة في لوحة المتابعة ← «حسابات الإدارة». ترسله إلى من تريد، فتفتحه وتنشئ حسابها بنفسها وتدخل مباشرة.
- **إيقاف حساب**: زر «إيقاف» بجانب كل حساب، ويمنع صاحبته من الدخول حتى لو فتحت رابط الدعوة من جديد.
- **تغيير الرابط**: يُبطل الرابط القديم فلا يمكن التسجيل به، ولا يؤثر في الحسابات المسجّلة.
- حسابات الإدارة ترى النتائج وتحذف التقييمات، ولا تستطيع إدارة الحسابات أو رابط الدعوة.

## ملاحظات
- رموز الفصول في الروابط: `m1-1` … `m3-3` للمتوسط، و`s1-1` … `s3-3` للثانوي. والروابط القديمة بصيغة `?class=ثاني متوسط 1` ما زالت تعمل.
- التقديرات: **متميز** (أخضر)، **جيد** (أزرق)، **يحتاج متابعة** (برتقالي). تقدير «متوسط» في النسخة السابقة يُعرض بوصفه «جيد».
- لا تستطيع المعلمات قراءة التقييمات أو تعديلها أو حذفها؛ القراءة والحذف للإدارة فقط وفق قواعد الحماية.
- التصدير بصيغة CSV يفتح مباشرة في Excel مع دعم الحروف العربية.
- النسخة الاحتياطية المرفقة في الحزمة السابقة تضم سجلين تجريبيين دون فصل محدد، ولم تُنقل.
